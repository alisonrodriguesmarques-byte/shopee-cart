## 📌 Sobre o Projeto

Este projeto é um **simulador de carrinho de compras inspirado na Shopee**, desenvolvido para rodar diretamente no **terminal com Node.js**.

A aplicação reproduz a lógica de um carrinho real, permitindo:

- adicionar itens  
- calcular subtotais  
- calcular o valor total automaticamente  
- organizar dados de forma modular  

💡 *O foco principal não é interface, mas sim a lógica por trás de sistemas reais de e-commerce.*

---

## ⚙️ Funcionalidades

- 🛍️ Adição de produtos ao carrinho  
- 📊 Cálculo automático de subtotal por item  
- 💰 Cálculo do total geral do carrinho  
- 🧩 Estrutura modular (separação de responsabilidades)  
- 🖥️ Execução via terminal
